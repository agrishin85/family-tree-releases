# Руководство пользователя FamilyTree

Версия FamilyTree: **0.9.16**

## Первый запуск

Скачайте из релиза файл `FamilyTree-…-win-x64-portable.exe` и запустите его двойным
щелчком. Установка, Node.js и npm для работы не нужны. Программа предназначена для
ведения генеалогической базы на вашем компьютере; данные сохраняются локально.

Рядом с программой в релизе доступны `CHANGELOG.md` с изменениями и `SHA256SUMS.txt`
с контрольными суммами exe и документов. Версию запущенного приложения можно
посмотреть в разделе «Настройки».

## Люди

В верхнем меню откройте «Люди». Добавьте человека, заполните фамилию и имя — эти
поля обязательны. Остальные сведения можно дополнить позднее: пол, даты и события,
другие имена, места жительства, занятия, фотографии, заметки и источники.
Если точная дата неизвестна, можно указать только известную часть даты.

Сохраните карточку. Добавленные сведения появятся в списке и сохранятся после
закрытия программы. Поиск фильтрует список по ФИО без учёта регистра. Страницы списка
переключаются панелями сверху и снизу.

Нажмите на строку человека, чтобы посмотреть подробные сведения и фотографии.
Кнопка редактирования открывает форму изменения. «Отмена» закрывает форму без
сохранения её изменений. Для удаления откройте редактирование и подтвердите
удаление. Вместе с человеком удаляются его связи; другие люди остаются в базе.

## Родственные и другие связи

Откройте «Связи» и добавьте связь между двумя уже созданными людьми. Участников
можно найти через поиск; недостающего человека можно добавить при выборе участника.
Укажите тип связи и, при необходимости, даты начала и окончания, место, заметку
и источник. Для родителя можно уточнить тип родительства, для партнёра — статус союза.

Связи также видны в подробной карточке человека. Здесь подпись описывает роль
другого участника относительно выбранного человека. Нажатие на участника открывает
его карточку; отдельная кнопка редактирования изменяет связь. Доступны поиск,
фильтр по типу и переключение страниц. Удаление связи не удаляет её участников.

## Дерево

Откройте «Дерево» и выберите главного человека через поиск. Кнопки перехода к дереву
есть также в списках людей и связей.

В широком окне главный человек находится в центре: родители слева сверху,
братья и сёстры справа сверху, дети слева снизу, партнёры справа снизу. В узком окне
группы располагаются вертикально. Если все родственники не помещаются в группу,
используйте её кнопки переключения.

Карточка позволяет посмотреть сведения о человеке или выбрать его новым главным
человеком. После возврата из просмотра положение группы сохраняется. Раскладка
автоматическая: перемещать карточки вручную не требуется. Сейчас отображается
ближайшее окружение выбранного человека, а не весь многопоколенный граф базы.

## Базы данных и фотографии

В разделе «Настройки» отображается полный путь текущей базы данных. По умолчанию
на Windows она находится в `%LOCALAPPDATA%\FamilyTree\family-tree.sqlite3`.

«Создать новую базу…» позволяет выбрать папку для пустой базы. Программа создаст
в ней файл `family-tree.sqlite3`; существующий файл с таким именем не заменяется.
«Выбрать файл базы…» открывает ранее созданную базу. Недавние базы доступны в списке
настроек для быстрого открытия. Выбранная база запоминается до следующего запуска.

Перед сменой базы сохраните или отмените открытое редактирование и дождитесь
окончания текущих операций. Открытие другой базы переключает отображаемые данные;
для объединения сведений используйте импорт.

Фотографии хранятся отдельно от файла базы, в соседней папке с суффиксом `.photos`,
например `family-tree.sqlite3.photos`. Перенос одного exe не переносит семейные данные.
Не удаляйте эту папку, если хотите сохранить фотографии.

## Резервная копия и перенос на другой компьютер

1. Закройте все запущенные экземпляры программы.
2. Скопируйте файл базы **вместе с соседней папкой фотографий** в безопасное место.
3. Для восстановления скопируйте оба элемента в выбранную папку и откройте файл
   базы через «Настройки» → «Выбрать файл базы…».

Перед обновлением приложения рекомендуется сделать такую копию: новая версия
может обновить формат базы, который старая версия уже не сможет открыть.

## Обмен GEDCOM и GEDZIP

В «Настройках» доступны экспорт и импорт. GEDCOM 7 (`.ged`) передаёт сведения и связи;
GEDZIP (`.gdz`) включает также фотографии. Экспортируйте GEDZIP для обмена с фото.
Для полной резервной копии приложения сохраняйте также исходную базу с её папкой фото.

Импорт добавляет или дополняет сведения в текущей базе. Перед импортом проверьте
путь базы и сделайте резервную копию. Существующие заполненные поля имеют приоритет;
пустые поля могут дополняться. Сопоставление учитывает ФИО и годы рождения/смерти:
проверьте итоговый отчёт и карточки, особенно для однофамильцев и людей без дат.
Неоднозначность или некорректные связи могут остановить импорт с сообщением об ошибке.
Повторный импорт одинаковых сведений не должен создавать повторные записи.

## Если возникла проблема

Если данные не видны, проверьте путь выбранной базы в «Настройках». Для отсутствующих
фотографий проверьте наличие соседней папки `.photos` и её содержимого. Не исправляйте
и не перемещайте открытый файл базы вручную.

При обращении за помощью укажите версию из настроек, версию Windows и текст ошибки.
Семейные данные и фотографии не нужно размещать в публичных сообщениях.

## Совместимость текущего выпуска

Portable-пакет предназначен для Windows x64. Запуск пакета проверялся на Windows 10 x64.
Windows 7 и 11 остаются целевыми системами, но требуют отдельной проверки запуска.
Для Linux готовый пакет пока не выпускается. Windows XP не поддерживается.
Текущий exe не имеет цифровой подписи.
